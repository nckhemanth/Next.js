# Labs

Run from the repo root:

```bash
npm install
npm run typecheck
npm run lab:all
```

The labs are intentionally small. The goal is not to build a second app here;
the goal is to make the key interview/project decisions executable:

- `01-rendering-decisions.ts` - choose static, cached, dynamic, or streamed rendering.
- `02-zod-server-action-shape.ts` - validate form data like a Server Action would.
- `03-ai-sdk-structured-output.ts` - define and validate the AI SDK structured output contract with Zod.
