# AGENTS.md

This repo contains public Next.js reference material and runnable examples.

Rules:

- Do not commit secrets, `.env` values, raw transcripts, or local notes.
- Keep explanations current with official Next.js, React, Auth.js, Sanity, Sentry, and AI SDK docs.

- Prefer practical examples, route trees, lifecycle diagrams, and concise explanations over vague summaries.
- Keep labs runnable with `npm run typecheck` from the repo root.
